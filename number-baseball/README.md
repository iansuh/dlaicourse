# 숫자 야구 (Number Baseball)

상대의 비밀 숫자를 먼저 맞히는 웹 게임. 컴퓨터 대결, 온라인 1:1, 팀전(N:N)을 지원합니다.

## 실행

```bash
cd number-baseball
node server.js          # http://localhost:3000  (PORT 환경변수로 변경 가능)
```

Node.js 18 이상만 있으면 되고 `npm install`이 필요 없습니다(외부 의존성 없음).

## 규칙

- 서로 다른 숫자 3~6개로 비밀 숫자를 정합니다. 0이 맨 앞에 와도 됩니다.
- 스트라이크(S): 숫자와 자리가 모두 맞음 / 볼(B): 숫자는 맞지만 자리가 다름 / 아웃(OUT): 맞는 숫자 없음.
- 매 라운드 양쪽이 동시에 추측합니다(선공 유불리 없음). 먼저 전부 스트라이크를 만들면 승리, 같은 라운드에 둘 다 맞히면 무승부.
- 팀전: 양 팀 인원이 같아야 하며(팀당 1~10명), 무작위로 1:1 짝을 지어 동시에 대결합니다. 더 많이 이긴 팀이 승리하고, 과반이 확정되면 즉시 종료됩니다.

## 기능

- **모드**: 컴퓨터 대결(쉬움/보통/어려움), 온라인 방(방 코드·초대 링크). 1:1은 팀당 1명인 팀전입니다.
- **시트 모드**: 화면을 스프레드시트처럼 표시합니다. `Esc`를 누르면 화면 전체가 가짜 매출 시트로 바뀌고, 다시 누르면 돌아옵니다.
- **작은 창**: 폭 240px 정도까지 사용할 수 있습니다.
- **언어**: 한국어, English, 日本語, 中文, Español, Français, Deutsch, Português, Русский, Tiếng Việt (`public/i18n.js`에 추가 가능).
- **메모**: 숫자 0~9를 눌러 제외/확정 표시.
- **입장**: 닉네임만 입력하면 됩니다(회원가입·비밀번호 없음). 대기 중인 방 목록에서 골라 들어가거나 방 코드로 참가합니다.
- **대기 중 연습**: 방을 만든 뒤 상대를 기다리는 동안 컴퓨터와 연습할 수 있고, 인원이 다 차면 자동으로 실제 대결이 시작됩니다.
- **채팅**: 방 안의 모든 사람이 함께 쓰는 채팅(최근 50개 유지).
- **모바일**: 터치 기기에서는 버튼과 입력칸이 커지고 숫자 키패드가 뜹니다.
- **후원 버튼**: `public/config.js`의 `donateUrl`에 후원 페이지 주소(https)를 넣으면 화면 아래에 표시됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `server.js` | 정적 파일 제공 + 게임 API(`/api/*`) + 실시간 푸시(Server-Sent Events). 판정은 서버가 하며 상대의 비밀 숫자는 대결이 끝나기 전까지 클라이언트로 전송되지 않습니다. |
| `public/app.js` | 화면과 컴퓨터 대결 로직 |
| `public/i18n.js` | 언어별 문자열 |
| `public/style.css` | 기본 스킨과 시트 모드 스킨 |

## 배포 시 참고

- Node를 실행할 수 있는 호스팅이면 됩니다(`npm start`). 저장소의 Root Directory를 `number-baseball`로 지정하세요.
- 도메인은 선택 사항입니다. 대부분의 호스팅이 무료 하위 도메인을 제공합니다.

- 방 상태는 서버 메모리에 있으므로 서버를 재시작하면 진행 중인 방이 사라지고, 서버 인스턴스는 1개로 운영해야 합니다.
- `public/`만 정적 호스팅(GitHub Pages 등)에 올리면 컴퓨터 대결만 동작합니다. 온라인 대결에는 `server.js`가 실행되는 Node 호스팅이 필요합니다.
- 게임 중 연결이 끊기면 2분 안에 재접속해야 하며, 넘기면 기권 처리됩니다. 2시간 동안 활동이 없는 방은 삭제됩니다.
